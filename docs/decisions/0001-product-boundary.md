# ADR-0001：产品仅管理与存档，不编排 Agent

- **状态**：Accepted（用户明确约束）
- **日期**：2026-10-30

## Context
多 Agent 与人共同开发需要任务、缺陷、用例、结果、证据、历史统一可查，但 Agent 运行由独立宿主和工具负责。

## Decision
Qual 只管理数据与业务状态，提供 REST API、MCP、CLI、Plugin/Skill；不做 Agent 任务执行、编排、调度、生命周期、模型推理、Prompt 托管、自动测试执行或 CI 调度。通过 API “领取”仅变更工作项负责人并写审计，不触发任何执行器。

## Consequences
架构更小，权限和审计成为核心；状态和历史可信度依赖外部上报来源与可校验证据。任何新增执行器提案都与本 ADR 冲突，必须另起产品决策，不允许作为实现细节绕过。

## Alternatives
“任务管理内建 Agent 执行平台”被排除：复杂度、职责与本产品目标不符。
